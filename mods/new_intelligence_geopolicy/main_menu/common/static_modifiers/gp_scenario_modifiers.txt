# v0.12.1 The four nudges (author, 2026-11-10: "a mild nerf of Morocco, a few bonuses for Poland, England a bit stronger,
# France slightly weaker"). Army strength can be moved only by a modifier, so these are the one honest exception to "no buffs
# for the AI": each is EVENT-DRIVEN (it starts with a dated historical event, never at game start), TEMPORARY (15 to 70 years),
# SMALL (3 to 10 %), named and explained in its description, and given only to an AI country (is_ai = yes) while neither of the
# game rules "Scenario marks" (gp_rule_scenario_mods) nor "Nudges" (gp_rule_nudges = gp_nudges_off) is off. Each one is on the
# author's veto list: delete the entry and its add_country_modifier line (named in the comment) and the nudge is gone. The AI's
# own evaluation (scores, threat, alliances) is the first lever; these only close the rest of the gap.
# Loc: gp_scen_l_*.yml (STATIC_MODIFIER_NAME_ / STATIC_MODIFIER_DESC_ carry the history and the numbers - keep them in step).
# ================================================================================================
