# Concentrated Warfare - game rules (module warscore_rules, SPEC section 10).
# Format: game/main_menu/common/game_rules/_game_rules.info and 00_game_rules.txt (research 03 section 4.1).
#
# * Every setting carries flag = general_rule, otherwise the rule is invisible in the game-rules UI
#   (in_game/gui/game_rules.gui only lists settings flagged general_rule / flavour_rule / multiplayer_rule).
# * Every setting also carries a flag named like itself. Vanilla script tests settings with has_game_rule = <setting key>
#   (e.g. has_game_rule = institution_spawn_random_city, a setting WITHOUT a self-named flag), and vanilla also adds
#   self-named flags (country_change_allowed, byz_name_*, timeout_*), so has_game_rule = cw_* resolves either way.
# * Loc keys: rule_<rule key>, setting_<setting key>, setting_<setting key>_desc.

# 1. Strength of the "army without headquarters" penalty.

#    unit modifier cw_no_hq_mild / cw_no_hq_harsh instead of cw_no_hq.

}
