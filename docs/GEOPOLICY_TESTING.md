# New Intelligence: Geopolicy — первый игровой тест

Чек-лист для первого запуска `mods/new_intelligence_geopolicy` (v0.1). Метрики логов — `bash tools/log_stats.sh` (см. `docs/research/13_ai_log_baseline.md`).

## 0. Подключение

1. Junction `Documents\Paradox Interactive\Europa Universalis V\mod\new_intelligence_geopolicy` → `mods\new_intelligence_geopolicy` — создан 2026-11-04.
2. Плейсет «New Intelligence: Geopolicy (test)» только с этим модом — создан в `playsets.json` 2026-11-04 и сделан активным (копия прежнего файла: `playsets.json.bak_20261104_212839_before_geopolicy`). Сначала тестируем порознь с Battle, потом вместе.
3. Новая партия 1337 (мод настраивает страны в `on_game_started_after_lobby`), промотать 2–3 месяца, выйти в рабочий стол.
4. Разбор логов делает Claude: `error.log` (строки с `gp_` = ошибки мода; отдельно `switch`, `ordered_present_country`, `religion.group`, `clear_saved_scope`, `influence_nation`, `debug_log` — реестр в `docs/GEOPOLICY_IMPLEMENTATION.md` §3) и `debug.log`.
5. **Диагностика в `debug.log`** (временная, `gp_debug_report`): блок строк на каждую из 22 стран (Бранденбург, Венгрия, османы, Франция, Англия, Польша, Москва, Кастилия, Византия, Сербия, Богемия, Австрия, Литва, Дания, Мамлюки, Шотландия, Новгород, Венеция, Грузия, Бретань, Корея, Золотая Орда) при старте партии и раз в год: `GP_REPORT BRA Brandenburg`, затем интервал доли домашнего региона, найдена ли угроза и во сколько раз она сильнее, импульс расширения, иноземцы, общий фронт, недавнее поражение, профиль зон (исторический / общий), роль и состояние. Если у Шотландии, Сербии, Новгорода по-прежнему «no regional threat» — поиск угрозы всё ещё сломан.

## 1. Дымовой тест (5 минут, игрок = Бранденбург)

- Правила игры: видно «Геополитика ИИ» (3 варианта), название и описания на русском.
- Решения → «Геополитический обзор»: три строки состояния, кнопка «Обновить отчёт» работает (после неё строка «доля измерена» зелёная).
- Глоссарий: понятия «Геополитика», «Угроза региону».
- Открыть ИИ-страну (Польша): во вкладке поведенческих модификаторов есть «Геополитика: …» и «Темперамент: европейский».
- Формируемые страны: у Шотландии (переключиться через консоль `tag SCO`) в списке есть «Альба» с описанием; у Боснии — «Иллирия»; у Галича — «Королевство Русь».

## 3. Что крутить

| Симптом | Ручка |
|---|---|
| ИИ не выходит за ядро | `gp_share_regional` 0.25 → 0.15 (и литерал в `gp_update_stage_zones`) |

| ИИ лезет через море | `gp_score_distance_discipline` −0.4/−0.7 → −0.6/−0.85 |

| Что смотреть | Где | Ожидание |
