# New Intelligence: Geopolicy — первый игровой тест

Чек-лист для первого запуска `mods/new_intelligence_geopolicy` (v0.1). Метрики логов — `bash tools/log_stats.sh` (см. `docs/research/13_ai_log_baseline.md`).

## 0. Подключение

1. Junction `Documents\Paradox Interactive\Europa Universalis V\mod\new_intelligence_geopolicy` → `mods\new_intelligence_geopolicy` — создан 2026-11-04.
2. Плейсет «New Intelligence: Geopolicy (test)» только с этим модом — создан в `playsets.json` 2026-11-04 и сделан активным (копия прежнего файла: `playsets.json.bak_20261104_212839_before_geopolicy`). Сначала тестируем порознь с Battle, потом вместе.
3. Новая партия 1337 (мод настраивает страны в `on_game_started_after_lobby`), промотать 2–3 месяца, выйти в рабочий стол.
4. Разбор логов делает Claude: `error.log` (строки с `gp_` = ошибки мода; отдельно `switch`, `ordered_present_country`, `religion.group`, `clear_saved_scope`, `influence_nation`, `debug_log` — реестр в `docs/GEOPOLICY_IMPLEMENTATION.md` §3) и `debug.log`.
5. **Диагностика в `debug.log`** (временная, `gp_debug_report`): блок строк на каждую из 22 стран (Бранденбург, Венгрия, османы, Франция, Англия, Польша, Москва, Кастилия, Византия, Сербия, Богемия, Австрия, Литва, Дания, Мамлюки, Шотландия, Новгород, Венеция, Грузия, Бретань, Корея, Золотая Орда; с v0.12.1 — 34 тега: добавлены Арагон, Португалия, Гранада, Марокко, Наварра, Тлемсен, Тунис, Галич, Волынь, Тевтонский орден, Киев, Смоленск, см. раздел 15) при старте партии и раз в год: `GP_REPORT BRA Brandenburg`, затем интервал доли домашнего региона, найдена ли угроза и во сколько раз она сильнее, импульс расширения, иноземцы, общий фронт, недавнее поражение, профиль зон (исторический / общий), роль и состояние. Если у Шотландии, Сербии, Новгорода по-прежнему «no regional threat» — поиск угрозы всё ещё сломан.

## 1. Дымовой тест (5 минут, игрок = Бранденбург)

- Правила игры: видно «Геополитика ИИ» (3 варианта), название и описания на русском.

- Глоссарий: понятия «Геополитика», «Угроза региону».
- Открыть ИИ-страну (Польша): во вкладке поведенческих модификаторов есть «Геополитика: …» и «Темперамент: европейский».
- Формируемые страны: у Шотландии (переключиться через консоль `tag SCO`) в списке есть «Альба» с описанием; у Боснии — «Иллирия»; у Галича — «Королевство Русь».

## 15. Тест v0.12.1: что смотреть в прогоне (2026-11-10)

Наблюдение 1337 → 1466 без игрока (в прошлый раз — около двух часов реального времени); **новая партия обязательна**. Всё ниже **не проверено в игре**. Что и почему сделано — `docs/GEOPOLICY_V012_PLAN.md`, раздел 4б; разбор жалоб автора по логам прошлой партии — [GEOPOLICY_OBSERVATION_1466.md](GEOPOLICY_OBSERVATION_1466.md); реестр допущений — `docs/GEOPOLICY_IMPLEMENTATION.md`, п. 81–103. Версию самого мода игра в `debug.log` не пишет (там только `version 1.4.*` — поддерживаемая версия игры из метаданных), поэтому прогон v0.12.1 узнаётся по блокам `GP_WAR` и по строкам `drive` / `pressure` в `GP_REPORT`; отчёт идёт для 34 тегов.

Правила игры по умолчанию: «Чужеземный захватчик» — «Общий фронт и союз» (скриптовые союзы включены), «Где действует захватчик» — «Только Иберия», «Исторические поправки» — «Включены» (работают, пока «Следы сценариев» не выключены). По желанию автора, необязательно: вторым прогоном для сравнения ванильное правило «Агрессивность ИИ» → «Низкая агрессивность» (ИИ начинает войны только при поводе, пауза между войнами 60 месяцев вместо 24; достижения блокируются — для наблюдателя неважно) — оно покажет, какая часть картины зависит от частоты войн, а не от выбора целей; мод это правило не меняет. **Логи читать до следующего запуска игры — она их обнуляет** (разбор — в конце раздела).

**Разбор логов после партии (до следующего запуска игры).** Игра обнуляет все логи при старте, поэтому сначала разбор, потом новый запуск. Из корня репозитория, Git Bash:

```bash
bash tools/gp_run_digest.sh -t CAS -t FRA
```
Скрипт копирует живые логи (`Documents\Paradox Interactive\Europa Universalis V\logs`) в `Documents\NewIntelligence\runs\<дата_время>\` и строит там `timeline.tsv` (события по годам), `wars.tsv` (год, время, нападающий, цель — имена стран как в игре), `newyear.tsv`, `reports.tsv` (год, тег, имя, время и строки годового `GP_REPORT` через « | ») и `war_blocks.tsv` (год, время и строки блока `GP_WAR` на каждое объявление войны). На экран: войны по 25-летним отрезкам, 15 самых воинственных стран, строки `gp_` с ошибками (должно быть пусто) и для каждого `-t ТЕГ` сжатая история годовых состояний страны. Ключи: `-d ПАПКА` — разобрать уже скопированные логи, `-o ПАПКА` — куда писать, `-t ТЕГ` — повторяемый, `-h` — справка. Нужны только `perl` и `awk` из Git Bash. `debug.log` содержит бинарные байты, читать его только через `grep -a`. Курс и показатели на момент объявления войны — в блоке `GP_WAR`; строка года объявления в `reports.tsv` уже может показывать `at war this year`. Примеры: `awk -F'\t' '$2=="CAS" && $1>=1418' reports.tsv | cut -c1-400`; `grep 'attacker FRA' war_blocks.tsv`. Две половины разбора можно запускать и по отдельности: `perl tools/gp_log_timeline.pl ПАПКА`, затем `perl tools/gp_log_reports.pl ПАПКА`.
