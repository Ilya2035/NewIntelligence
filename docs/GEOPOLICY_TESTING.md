# New Intelligence: Geopolicy — первый игровой тест

Чек-лист для первого запуска `mods/new_intelligence_geopolicy` (v0.1). Метрики логов — `bash tools/log_stats.sh` (см. `docs/research/13_ai_log_baseline.md`).

## 0. Подключение

1. Junction `Documents\Paradox Interactive\Europa Universalis V\mod\new_intelligence_geopolicy` → `mods\new_intelligence_geopolicy` (создаётся командой из README).
2. Лаунчер → плейсет «New Intelligence: Geopolicy (test)» только с этим модом (без Battle — сначала порознь, потом вместе).
3. Новая партия 1337 (мод меняет стартовые данные через `on_game_started_after_lobby`).
4. Сразу после загрузки: `grep -i "gp_" Documents/.../logs/error.log` — должно быть пусто (строки с `gp_` = ошибки мода). Отдельно проверить `switch`, `ordered_present_country`, `religion.group`, `clear_saved_scope`, `influence_nation` (реестр в `docs/GEOPOLICY_IMPLEMENTATION.md` §3).

## 1. Дымовой тест (5 минут, игрок = Бранденбург)

- Правила игры: видны «Геополитика ИИ» (3 варианта) и «Defines геополитики» (2 варианта), названия и описания на русском.
- Решения → «Геополитический обзор»: три строки состояния, кнопка «Обновить отчёт» работает (после неё строка «доля измерена» зелёная).
- Глоссарий: понятия «Геополитика», «Угроза региону».
- Открыть ИИ-страну (Польша): во вкладке поведенческих модификаторов есть «Геополитика: …» и «Темперамент: европейский».
- Формируемые страны: у Шотландии (переключиться через консоль `tag SCO`) в списке есть «Альба» с описанием; у Боснии — «Иллирия»; у Галича — «Королевство Русь».

## 3. Что крутить

| Симптом | Ручка |
|---|---|
| ИИ не выходит за ядро | `gp_share_regional` 0.25 → 0.15 (и литерал в `gp_update_stage_zones`) |
| слишком много войн у мелких | `gp_role_consolidator`: `ai_months_between_wars` −6 → 0, `aggressiveness_modifier` 0.15 → 0.1 |
| угрозы «видят все» | `gp_threat_ratio_min` 1.5 → 2.0 |
| никого не признают угрозой | 1.5 → 1.25; проверить п. 3–4 реестра |
| границы всё ещё рваные | `CONQUER_DESIRE_AREA_COMPLETE_BONUS` 70 → 100, `AREA_RAMP_START` 0.4 → 0.3 |
| ИИ лезет через море | `gp_score_distance_discipline` −0.4/−0.7 → −0.6/−0.85 |
