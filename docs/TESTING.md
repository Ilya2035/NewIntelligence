# Тестирование мода

## 0. Перед запуском
```bash
bash tools/validate.sh
```
Должно быть `RESULT: OK` и без новых предупреждений про «unknown key».

## 1. Запуск
0. Мод подключён к игре через junction `Documents\Paradox Interactive\Europa Universalis V\mod\new_intelligence_battle` → `<репозиторий EU5-NewIntelligence>\mods\new_intelligence_battle` (создать один раз: `mklink /J "%USERPROFILE%\Documents\Paradox Interactive\Europa Universalis V\mod\new_intelligence_battle" "C:\Users\fyrno\PycharmProjects\EU5-NewIntelligence\mods\new_intelligence_battle"`; старый junction `mod\concentrated_warfare` удалить).
1. Лаунчер EU5 → Плейсеты → включить «New Intelligence: Battle» (рекомендуется отдельный плейсет без читов для первого теста).
2. Новая партия за среднюю страну (Франция, Кастилия, Москва), дата 1337.
3. Сразу после загрузки открыть `Documents\Paradox Interactive\Europa Universalis V\logs\error.log` и отфильтровать строки с `cw_` — это ошибки мода. Полезные фильтры в Git Bash:
   ```bash
   grep -i "cw_" "/c/Users/fyrno/Documents/Paradox Interactive/Europa Universalis V/logs/error.log" | sort | uniq -c | sort -rn | head -40
   ```
