## 2. Годовой проход (`gp_yearly_update`, страна сохраняется как `scope:gp_c`)

1. `gp_compute_region_share` — обход `capital.region = { every_ownable_location_in_region }`, счёт в двух временных переменных, результат `var:gp_region_share` (0…1).
2. `gp_update_threat` — снять прошлогоднее мнение и переменные; `save_scope_as = gp_self`; `capital.region = { ordered_present_country = { limit = { gp_is_threat_candidate } order_by = country_strength max = 1 } }`, запасной вариант `ordered_neighbor_country`; результат `var:gp_threat`, `var:gp_threat_ratio`, мнение `gp_opinion_regional_threat`; `clear_saved_scope`.
3. `gp_update_intruders` — `every_present_country` региона с `gp_is_intruder` → мнение `gp_opinion_foreign_intruder` (remove + add).
4. `gp_update_common_front` — те же, у кого `var:gp_threat` совпадает с нашим и та же религиозная группа → `gp_opinion_common_enemy`.
5. Если правило не «off»: `gp_update_role` (осаждённая → империя → гегемон → региональная → статус-кво → собиратель; переменная `gp_role_*`), только ИИ — `gp_update_stage_zones` (сфера при доле ≥ 0.25, дальняя при ≥ 0.55; иначе снять). При «off» роли стираются.
6. `gp_debug_report` — временный отчёт `GP_REPORT` в `debug.log` (18 стран в v0.1, 22 в v0.12.0, 34 тега в v0.12.1).

Модификаторов страны нет. Видимые следы мода у страны — только мнения («Угрожает нашему региону», «Иноземная сила в нашем регионе», «Общая угроза региону»), обычный ванильный механизм отношений. В цикле старта партии `root` — не страна (первый запуск 2026-11-04), поэтому весь проход работает через `scope:gp_c`.

**v0.12.1: что изменилось в годе ИИ-страны.** Порядок: `gp_compute_region_share` → `gp_update_momentum` → `gp_update_invader` (флаг и память захватчика, до угрозы) → `gp_update_threat` → … → `gp_update_role` → `gp_update_drive` → `gp_update_pressure` → `gp_update_posture` (раз в год подтверждает и личность ИИ) → `gp_update_stage_zones`, `gp_update_directions`, `gp_update_overseas` → `gp_update_vanilla_pull` → `gp_inv_pact_upkeep` → `gp_debug_report`. Угроза ищется в три слоя: (1) чужеземный захватчик (список `gp_inv_list`, затем плацдарм — три локации нашего региона; флаг `gp_threat_invader`), (2) `gp_is_threat_candidate` — не союзник и не старый друг, плюс победитель в нашей последней проигранной войне (`gp_beaten_by`, 12 лет), (3) сосед; флаги `gp_threat_near` (рядом: сосед, столица в нашем регионе, три наши локации, граница ближе 100, захватчик, победитель) и `gp_threat_home`. В конце проигранной войны (`gp_on_war_end_effect`) работают `gp_inv_war_end`, `gp_set_beaten_by`, `gp_pressure_war_lost`, и курс пересчитывается сразу.

Напор `gp_drive` = `110 × (0,55 − доля региона)` для ведущей державы региона, который война может объединить (`30 ×` для германских земель), +15 чужак в регионе, +15 смута, +20 идущее завоевание, +15 угроза вдвое сильнее, +10 назначена подготовленная война; не больше 100, а у побитой, безнадёжной, осаждённой или сохранившей меньше половины лучшей доли — не больше 15. Давление `gp_pressure` = угроза `(доля − 0,5) × 100` (до 35; вдвое меньше, если не рядом; ×1,4 у захватчика) + потерянная земля `(0,9 − сохранённое) × 36` + война (годы подряд после второго ×2 до 12, проигрываемая война +10, усталость выше 3 ×2,5 до 15) + кризис ×0,12 (до 12) + память о проигранных войнах (+10 за войну, ×0,78 в год), ×0,75 у наступающей державы; `gp_pr_hot` включается с 45 и гаснет ниже 30, `gp_is_pressed` — с 40. Восемь из девяти оценок курса `gp_ps_*` (все, кроме изоляции) читают только давление выше колена (`gp_pressure_excess`, колено 15, ручка `gp_pressure_scale`), оценки и списки целей — всё давление (`gp_pressure_load`). Личность ИИ (`gp_apply_personality`): горячее давление — оборонительная с угрозой и осторожная без неё; подготовка при напоре от 50 — агрессивная, подготовка и экспансия от 30 — экспансионистская, оппортунизм от 30 — оппортунистская, при меньшем напоре — ванильный темперамент, запомненный при старте (`gp_base_temper`), но не горячее «сбалансированного».

Мод по-прежнему не вешает на ИИ постоянных бонусов; исключение — четыре временные исторические поправки v0.12.1 по прямой просьбе автора (правило `gp_rule_nudges`, список и вето — `docs/GEOPOLICY_V012_PLAN.md`, раздел 4б).

## 4. Производительность

- Ни одного ежемесячного цикла по странам. Годовой проход: ~900 настоящих стран; обход локаций региона столицы (крупные регионы ~500 локаций) и список стран, присутствующих в регионе (в раздробленной Германии ~100). Оценка: < 1 с реального времени в год на среднем ПК (проверить п. 12).
- Дипломатические цели: `days_between_checks = 365`, без `recipient_list_builder` (фильтр `recipient_trigger` по всем достижимым странам).
- Оценки целей расширения считаются движком только для `AI_NUM_EXPANSION_TARGETS = 20` кандидатов.

## 5. Совместимость

- Заменяет один ванильный файл — `in_game/gui/expansion_lateralview.gui` (с v0.11, ради панели колонии; сверка после патчей — `tools/vanilla_overrides.txt`); остальные вклады — свои файлы с префиксом `gp_`. Под ванильными ключами `on_action` — только `on_actions = { gp_x }` (слияние одноимённых on_action). Копии ванильных записей по ключу — не файлы, и `tools/check_vanilla_overrides.sh` их не видит (он сверяет файлы целиком), поэтому после каждого патча игры их сверяют с ванилью вручную: `REPLACE:alliance` (`in_game/common/scripted_relations/gp_alliance.txt`, ванильное отношение `alliance` из `scripted_relations`) и, с v0.12.1, `REPLACE:hundred_years_war_wargoal` (`in_game/common/wargoals/gp_wargoals.txt`: тело ванильной цели из `in_game/common/wargoals/00_default.txt`, строки 606–652, с изменённым `allowed_locations` обеих сторон).
- С Battle (`cw_`) ключи не пересекаются; оба мода вешают разные страновые модификаторы с `ai = yes`, они складываются.
- Новые теги не объявлены в `setup/countries` (как ванильные NSE / CEL / HEN): цвет и имя приходят из формируемой страны, герб — по ключу тега.
- При патче: пересверить номера строк и ванильные значения в `gp_defines.txt`; `bash tools/validate.sh new_intelligence_geopolicy` и `bash tools/check_geopolicy_refs.sh`.
- Урок первого запуска Battle, учтённый здесь: на стадии `main_menu` неизвестны внутриигровые триггеры (`current_age_or_later`) — все файлы мода в `main_menu/` (правила, модификаторы, понятия, цвета, гербы) триггеров не содержат.

## 6. Что сознательно не сделано в v0.1

- Нет интерфейса, кроме понятий (решение-отчёт убрано в v0.8 по просьбе автора); переменные (доля, угроза) в подсказках не выводятся (синтаксис показа переменных в loc не подтверждён).
- Нет ванильных `rival_criteria` для мажоров (только теги; угроза уже влияет на мнение и цели).
- Личности ИИ (`ai_personalities`) не переопределяются — роли складываются с ними.
- Колониальные зоны оставлены ванильным предпочтениям (`castile_conquer_new_world`, exploration_preferences).
