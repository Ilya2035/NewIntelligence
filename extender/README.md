# New Intelligence — программа-расширение (личная)

Ставит моды New Intelligence в EU5, держит резервные копии, проверяет целостность игры, возвращает игру к заводскому состоянию и собирает наше обратно. Только для себя: в Steam и мастерскую не выкладывается. Почему так и что дальше — [docs/EXTENDER_FEASIBILITY.md](../docs/EXTENDER_FEASIBILITY.md), раздел 7.

## Запуск

Двойной щелчок по `NewIntelligence.cmd` открывает меню. Из консоли:

```
NewIntelligence.cmd status
NewIntelligence.cmd factory -RemoveMods
NewIntelligence.cmd apply
NewIntelligence.cmd verify -Steam
NewIntelligence.cmd report
```

| Команда | Что делает |
|---|---|
| `status` | что стоит: игра, сборка, моды, чит-мод, движок, целостность (`-Json` — для Claude) |
| `backup` | резервная копия модов, `playsets.json` и состояния |
| `snapshot` | отпечаток заводских файлов движка для текущей сборки (снимать на чистой игре) |
| `verify` | сверка с отпечатком; `-Steam` — ещё и проверка файлов в Steam |
| `factory` | заводское состояние: наши правки движка убраны, наши моды вычеркнуты из сборок модов; `-RemoveMods` — убрать и папки модов |
| `apply` | наше состояние: моды на месте и включены, чит-мод включён, правки движка для этой сборки |
| `report` | отчёт из журналов: какие моды загрузились, ошибки наших модов, строки `GP_REPORT` |

`-DryRun` показывает, что будет сделано, ничего не меняя.

## Правила, зашитые в программу

- Пока игра запущена, ничего не меняет.
- Перед `factory` и `apply` делает резервную копию в `Документы\NewIntelligence\backups`.
- Пишет только в `mod\`, `playsets.json`, свою папку `Документы\NewIntelligence` и в файлы движка из `ni_profile.json`.
- Никогда не трогает `game\`, `game\dlc`, владение DLC, Steam, сохранения и `dlc_signature`. Ничего не скачивает и ничего не прячет от игры.
- Чужие файлы в папке игры только показывает, но не удаляет.
- Правка движка ставится только на ту сборку `eu5.exe`, для которой сделана.

## Настройка

`ni_profile.json` задаёт:

- какие моды ставить (Battle и Geopolicy из этого репозитория);
- какой мод обязателен (Cheat Menu Pro, id 3600272327);
- файлы движка: `version.dll` (загрузчик E1) из `engine\bin`.

## Движок (загрузчик E1)

- `engine\build.ps1` — собрать `version.dll` под текущий `eu5.exe`. Нужен w64devkit в `%USERPROFILE%\Tools\w64devkit`.
- `engine\tests\run_tests.ps1` — проверить загрузчик без игры.
- `apply` ставит загрузчик в `binaries`, `factory` убирает.
- Журнал загрузчика: `Документы\NewIntelligence\engine.log`. Выключатель: создать файл `Документы\NewIntelligence\engine_off`.

E1 в игре ничего не меняет: только проверяет, что это та сборка `eu5.exe`, и пишет журнал.

Пока в Windows включён «Интеллектуальный контроль приложений», Windows не загружает неподписанную DLL. Поэтому `apply` загрузчик не ставит: игра с заблокированным `version.dll` не запустится. Подробности и выходы — в [docs/EXTENDER_FEASIBILITY.md](../docs/EXTENDER_FEASIBILITY.md), раздел 8.
